# Contexto Global del Proyecto (contexto/)

Este directorio contiene la información fundacional de dominio que los agentes deben conocer. Se estructura en archivos atómicos numerados para permitir la carga selectiva según la naturaleza de la tarea, respetando el principio de **Economía de Contexto (SDS-500)**.

## Archivos Base
- `01-negocio.md`: Visión del producto, modelo de negocio y propuesta de valor.
- `02-datos-sensibles.md`: Clasificación de datos (PII, secretos) y restricciones de manejo.
- `03-integraciones.md`: Servicios externos, contratos de red y APIs de terceros.
- `04-regulaciones.md`: Marcos legales o normativos aplicables (GDPR, SOC2, PCI-DSS).
- `05-audiencias.md`: Segmentación de usuarios y arquetipos de interacción.
- `06-estandares-frontend.md`: Directivas de diseño de interfaz, accesibilidad y componentes.
