# Topografía de Arquitectura del Proyecto (MAPS/)

Este directorio contiene los mapas conceptuales y topográficos del proyecto. Sirve como ancla espacial para que los agentes comprendan la estructura modular, las dependencias entre servicios y los límites de dominio antes de planificar cambios.

## Estructura
- `ATLAS-TEMPLATE.md`: Plantilla viva de topografía con diagramas Mermaid embebidos.
- Mapas específicos por subsistema o flujos de datos.
